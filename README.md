# שרתי Bluefeed: התקנת NixOS

‏הריפו הזה מגדיר את השרתים כקוד. ההתקנה נעשית מהמחשב הנייד שלך, דרך הרשת, אחרי שמאתחלים את השרת מדיסק און קי. סקריפט אחד מוחק את הדיסק של השרת, מתקין NixOS עם כל הגדרות האבטחה, ומאתחל. אין צורך להקליד הגדרות ידנית על השרת.

‏סדר העבודה: מכינים את המחשב הנייד (שלב 1), מאתחלים את השרת מדיסק און קי ואוספים ממנו פרטים (שלב 2), ממלאים קובץ הגדרות אחד (שלב 3), מתקינים (שלב 4), ובודקים שהכל עובד (שלב 5).

## שלב 1: הכנת המחשב הנייד

‏צריך מחשב נייד שמחובר לאותה רשת ביתית כמו השרת, עם Linux, Mac או Windows עם WSL.

‏מתקינים את Nix לפי ההוראות ב-https://nixos.org/download. אחר כך מפעילים את התכונות ש-Nix צריך בשביל הריפו הזה:

```
mkdir -p ~/.config/nix && echo "experimental-features = nix-command flakes" >> ~/.config/nix/nix.conf
```

‏מורידים את הריפו (צריך הרשאה מרון לריפו ב-GitHub):

```
git clone https://github.com/ronmandeles/bluefeed-server
cd bluefeed-server
```

‏יוצרים שני מפתחות SSH, אם עוד אין לך. הראשון הוא המפתח האישי שלך לניהול השרת. השני הוא מפתח נפרד לפריסת האפליקציה, שלא נותן הרשאות ניהול:

```
ssh-keygen -t ed25519
ssh-keygen -t ed25519 -f ~/.ssh/bluefeed_deploy
```

## שלב 2: אתחול השרת מדיסק און קי ואיסוף פרטים

‏מורידים את "Minimal ISO image" של NixOS מ-https://nixos.org/download, צורבים אותו לדיסק און קי (למשל עם balenaEtcher), ומאתחלים ממנו את השרת. השרת עולה למסך טקסט עם משתמש מחובר. מריצים עליו את הפקודות הבאות ורושמים את התשובות.

‏הפקודה `uname -m` צריכה להחזיר `x86_64`. אם מתקבל משהו אחר, עוצרים ומעדכנים את רון.

‏הפקודה `ip a` מציגה את כתובת ה-IP של השרת, למשל `192.168.1.50`.

‏הפקודה `lsblk` מציגה את הדיסקים. מזהים את הדיסק שעליו מתקינים לפי הגודל שלו. אחר כך `ls -l /dev/disk/by-id/` מציגה את השם הקבוע של אותו דיסק, למשל `/dev/disk/by-id/nvme-Samsung_SSD_980_...`.

‏הפקודה `sudo passwd root` קובעת סיסמה זמנית, שמשמשת רק להתקנה ונמחקת בסופה.

‏משאירים את השרת דלוק על המסך הזה.

## שלב 3: מילוי קובץ ההגדרות

‏הקובץ היחיד שעורכים הוא `hosts/bluefeed-server/settings.nix`. כל שדה בו מסומן במספר שאלה (Q2 עד Q5), וזה מה שממלאים בכל אחד:

‏**Q2 (`lanSubnets`): טווח הרשת הביתית.** רק מחשבים בטווח הזה יוכלו להתחבר לשרת. אם כתובת השרת היא `192.168.1.50`, הטווח הוא בדרך כלל `192.168.1.0/24`. מומלץ גם להגדיר בראוטר כתובת IP קבועה לשרת (DHCP reservation).

‏**Q3 (`disk`): הדיסק להתקנה.** השם הקבוע מ-`/dev/disk/by-id/` משלב 2. שימו לב, ההתקנה מוחקת את הדיסק הזה לגמרי.

‏**Q4 (`admin`): משתמש המנהל.** שם המשתמש שלך בשרת (ברירת המחדל `ilya`), והמפתח הציבורי האישי שלך. מציגים אותו עם `cat ~/.ssh/id_ed25519.pub` ומעתיקים את כל השורה, שמתחילה ב-`ssh-ed25519`. למשתמש הזה יש sudo בלי סיסמה, כי הכניסה היא עם מפתח בלבד. השורה של רון נשארת בהערה, אלא אם רון צריך גישה.

‏**Q5 (`deploy`): מפתח הפריסה.** התוכן של `~/.ssh/bluefeed_deploy.pub`.

‏את ערכי האפליקציה (`app`) רון כבר מילא, ואין צורך לשנות אותם.

## שלב 4: התקנה

‏מתוך תיקיית הריפו במחשב הנייד:

```
./scripts/install.sh bluefeed-server <IP-של-השרת>
```

‏הסקריפט מציג איזה דיסק יימחק ומבקש להקליד `yes`. אחר כך הוא מבקש את הסיסמה הזמנית משלב 2, ומשם עובד לבד, בערך 10 עד 30 דקות. במחשב Mac מריצים במקום זה `BUILD_ON_SERVER=1 ./scripts/install.sh bluefeed-server <IP>`, כדי שהבנייה תתבצע על השרת.

‏בסוף ההתקנה השרת מאתחל את עצמו. מוציאים את הדיסק און קי.

## שלב 5: בדיקה ושמירה

‏מתחברים לשרת עם `ssh ilya@<IP>`. אם הכניסה עובדת, ההתקנה הצליחה.

‏כדי לוודא שהחסימות עובדות, מריצים `ssh root@<IP>`. הניסיון הזה צריך להיכשל.

‏ההתקנה יצרה שני קבצים שצריך לשמור בריפו: `hosts/bluefeed-server/hardware-configuration.nix`, שמכיל את החומרה שזוהתה, ו-`flake.lock`, שמכיל את הגרסאות המדויקות שהותקנו. בסוף ההתקנה הסקריפט מדפיס את פקודת ה-git ששומרת אותם יחד עם `settings.nix`. אם אין לך הרשאת push לריפו, שולחים את שלושת הקבצים לרון.

## אחרי ההתקנה

‏עדכוני אבטחה מותקנים אוטומטית כל לילה ב-04:00. השרת לא מאתחל את עצמו, ולכן עדכון קרנל ייכנס לתוקף רק באתחול הבא.

‏כדי להחיל על השרת שינוי בקבצים מריצים `./scripts/update-server.sh bluefeed-server ilya@<IP>`. אם משהו נשבר, אפשר לבחור את הגרסה הקודמת בתפריט האתחול של השרת.

‏כדי לפרוס גרסה של האפליקציה מריצים `./scripts/deploy-app.sh bluefeed-server deploy@<IP> <flake>#<package>`. לבדיקה, אפשר לפרוס את אפליקציית הדמו עם `.#bluefeed-server-demo-app` ולפתוח בדפדפן את `http://<IP>:8080`.

## הוספת שרת נוסף

‏כל תיקייה תחת `hosts/` היא שרת, ושם התיקייה הוא שם השרת. כדי להוסיף שרת, מעתיקים את `hosts/bluefeed-server` לתיקייה חדשה, למשל `hosts/bluefeed-server-2`, מוסיפים אותה ל-git עם `git add`, ממלאים את `settings.nix`, ומתקינים עם `./scripts/install.sh bluefeed-server-2 <IP>`.

## מה כל קובץ עושה

‏`hosts/<שרת>/settings.nix` מכיל את כל הערכים הייחודיים לשרת. זה הקובץ היחיד שעורכים.

‏`hosts/<שרת>/hardware-configuration.nix` נכתב אוטומטית בזמן ההתקנה, לפי החומרה של השרת.

‏`flake.nix` הוא נקודת הכניסה. הוא קובע את גרסת NixOS (26.05) ובונה תצורה לכל שרת תחת `hosts/`.

‏`modules/base.nix` מגדיר את האבטחה: חומת אש שמאפשרת רק SSH ואת פורט האפליקציה ורק מהרשת הביתית, SSH עם מפתחות בלבד ובלי root, שני משתמשים, עדכונים אוטומטיים, והגדרות Nix.

‏`modules/disk.nix` מגדיר את חלוקת הדיסק. היא עובדת גם ב-UEFI וגם ב-BIOS.

‏`modules/app.nix` מריץ את האפליקציה כשירות בלי root ובתוך ארגז חול. משתמש ה-deploy מורשה רק להפעיל אותה מחדש.

‏`tests/server-test.nix` הוא בדיקת אבטחה אוטומטית במכונות וירטואליות. מריצים אותה עם `nix flake check`, אבל זה לא חובה.

‏בתיקייה `scripts/` נמצאים הסקריפטים להתקנה, לעדכון השרת ולפריסת האפליקציה.
