# שרת Bluefeed: התקנת NixOS

‏הריפו הזה הוא השרת כולו, כתוב כקוד. ממלאים קובץ אחד (`settings.nix`), מאתחלים את השרת מדיסק און קי, ומריצים סקריפט אחד מהמחשב הנייד. הסקריפט מוחק את הדיסק, מתקין NixOS עם כל ההקשחה, ומאתחל.

‏ההגדרות כבר נבדקו אוטומטית בשלוש מכונות וירטואליות (שרת, מחשב ברשת הביתית ומחשב מחוץ לה): כניסה עם מפתח עובדת, root וסיסמאות חסומים, משתמש ה-deploy לא יכול לקבל root, פריסת אפליקציה עובדת, ומחשב מחוץ לרשת הביתית לא מגיע לשרת.

## שלב 1: לענות על השאלות ולמלא את settings.nix

‏כל שאלה מסומנת באותו מספר גם בתוך `settings.nix`.

‏**Q1. מחשב נייד ומעבד השרת.** צריך מחשב נייד באותה רשת כמו השרת, עם Linux, Mac או Windows עם WSL, ועליו Nix. להתקנת Nix יש הוראות ב-https://nixos.org/download. בנוסף, הסקריפטים מניחים שהשרת הוא מעבד Intel/AMD רגיל. אחרי האתחול מהדיסק און קי (שלב 2), הפקודה `uname -m` צריכה להחזיר `x86_64`. אם מתקבל משהו אחר, לעצור ולעדכן את רון.

‏**Q2. טווח הרשת הביתית (`lanSubnets`).** רק מחשבים בטווח הזה יוכלו להגיע לשרת. במחשב הנייד מריצים `ip a` ב-Linux, או `ipconfig getifaddr en0` ב-Mac. אם הכתובת היא למשל `192.168.1.23`, הטווח הוא `192.168.1.0/24`. מומלץ גם להגדיר בראוטר כתובת IP קבועה לשרת (DHCP reservation).

‏**Q3. הדיסק להתקנה (`disk`).** ההתקנה מוחקת את הדיסק הזה לגמרי. אחרי האתחול מהדיסק און קי מריצים על השרת `lsblk` כדי לזהות את הדיסק לפי הגודל, ואז `ls -l /dev/disk/by-id/` כדי לקבל את השם הקבוע שלו (למשל `/dev/disk/by-id/nvme-Samsung_SSD_...`). משתמשים בשם הקבוע ולא ב-`/dev/sda`, כי השם הקצר יכול להשתנות בין אתחולים.

‏**Q4. משתמש המנהל (`admin`).** שם המשתמש שלך בשרת (ברירת המחדל `ilya`) והמפתח הציבורי שלך. אם אין לך מפתח, יוצרים אחד עם `ssh-keygen -t ed25519`, ואת המפתח הציבורי מקבלים עם `cat ~/.ssh/id_ed25519.pub`. מעתיקים את כל השורה, שמתחילה ב-`ssh-ed25519`. למשתמש הזה יש sudo בלי סיסמה, כי אין לו סיסמה בכלל אלא רק מפתח. המפתח של רון מופיע כשורה בהערה, ומפעילים אותו רק אם רון צריך גישה.

‏**Q5. מפתח ה-deploy (`deploy`).** זה מפתח נפרד, שמשמש רק לפריסת גרסאות של האפליקציה ולא נותן הרשאות ניהול. יוצרים אותו במחשב שממנו יפרסו את האפליקציה: `ssh-keygen -t ed25519 -f ~/.ssh/bluefeed_deploy`, ומעתיקים את התוכן של `~/.ssh/bluefeed_deploy.pub`.

‏**Q6. שם השרת (`hostName`).** ברירת המחדל היא `bluefeed-server`. אפשר להשאיר אותה.

‏את ערכי האפליקציה (`app`) רון כבר מילא, ואין צורך לשנות אותם.

## שלב 2: לאתחל את השרת מדיסק און קי

‏מורידים את "Minimal ISO image" של NixOS מ-https://nixos.org/download וצורבים אותו לדיסק און קי (למשל עם balenaEtcher). מאתחלים את השרת ממנו, ואז מריצים על המסך של השרת:

‏הפקודה `sudo passwd root` קובעת סיסמה זמנית לצורך ההתקנה בלבד. היא נמחקת בסוף ההתקנה.

‏הפקודה `ip a` מציגה את כתובת ה-IP של השרת.

‏הפקודות `lsblk` ו-`uname -m` עונות על Q3 ו-Q1.

## שלב 3: להתקין

‏במחשב הנייד, מתוך תיקיית הריפו:

```
./scripts/install.sh <IP-של-השרת>
```

‏הסקריפט מבקש אישור (צריך להקליד `yes`), את הסיסמה הזמנית, ואחר כך עובד לבד. במחשב Mac מריצים במקום זה `BUILD_ON_SERVER=1 ./scripts/install.sh <IP>`, כדי שהבנייה תתבצע על השרת ולא על ה-Mac.

‏בסוף ההתקנה השרת מאתחל את עצמו. מוציאים את הדיסק און קי ומתחברים עם `ssh ilya@<IP>`.

‏ההתקנה יוצרת או מעדכנת שני קבצים, `hardware-configuration.nix` (החומרה שזוהתה) ו-`flake.lock` (הגרסאות המדויקות שהותקנו). צריך לשמור את שניהם בריפו:

```
git add hardware-configuration.nix flake.lock && git commit -m "Server installed" && git push
```

## אחרי ההתקנה

‏עדכוני אבטחה מותקנים אוטומטית כל לילה ב-04:00. השרת לא מאתחל את עצמו, ולכן עדכון קרנל ייכנס לתוקף רק באתחול הבא.

‏כדי להחיל שינוי בקבצים על השרת: `./scripts/update-server.sh ilya@<IP>`. אם משהו נשבר, בתפריט האתחול של השרת אפשר לבחור את הגרסה הקודמת.

‏כדי לפרוס גרסה של האפליקציה: `./scripts/deploy-app.sh deploy@<IP> <flake>#<package>`. לבדיקה, אפשר לפרוס את אפליקציית הדמו עם `.#demo-app` ולפתוח את `http://<IP>:8080`.

## מה כל קובץ עושה

‏`settings.nix` מכיל את כל הערכים הייחודיים לשרת. זה הקובץ היחיד שעורכים.

‏`flake.nix` הוא נקודת הכניסה. הוא קובע את גרסת NixOS (26.05) ומחבר את כל הקבצים.

‏`configuration.nix` מגדיר את ההקשחה: חומת אש שמאפשרת רק SSH ואת פורט האפליקציה, ורק מהרשת הביתית, SSH עם מפתחות בלבד ובלי root, שני משתמשים, עדכונים אוטומטיים, והגדרות Nix.

‏`disk.nix` מגדיר את חלוקת הדיסק. היא עובדת גם ב-UEFI וגם ב-BIOS.

‏`hardware-configuration.nix` נכתב אוטומטית בזמן ההתקנה, לפי החומרה של השרת.

‏`modules/app.nix` מריץ את האפליקציה כשירות בלי root ובתוך ארגז חול. משתמש ה-deploy מורשה רק להפעיל אותה מחדש.

‏`tests/server-test.nix` הוא בדיקת האבטחה האוטומטית. מריצים אותה עם `nix flake check`, וזה לא חובה.

‏בתיקייה `scripts/` נמצאים הסקריפטים להתקנה, לעדכון השרת ולפריסת האפליקציה.
